## Recommended use

1. Print or open one chapter PDF and keep the answer section closed.
2. Stop when the suggested time expires.
3. Grade with the quick key, then read the worked solutions only for missed or uncertain items.
4. Record whether each miss came from a concept, formula setup, indexing, synchronization, or arithmetic error.

The problem style follows the course practice midterm: true/false with justification, short definitions, quantitative performance analysis, CUDA code reasoning, and parallel-programming design questions.
